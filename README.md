# dps_slam_docker

Docker + colcon workspace for [**DPS-SLAM**](https://github.com/perezsaura-david/dps_slam) (Dual
Pose-graph Semantic SLAM for AeroStack2). This repo provides the container and a vcstool manifest
that assembles the whole workspace — the `dps_slam` node, its messages, and g2o — so anyone can
reproduce the same development environment.

The image is ROS 2 Humble + Gazebo Harmonic and installs g2o's system dependencies
(`libsuitesparse-dev`, `libgoogle-glog-dev`). g2o itself and the project packages are pulled as
source by `vcs import` and built in-container by colcon.

## Contents

| File | Purpose |
|------|---------|
| `dockerfile` | The image: base `aerostack2/nightly-humble`, Gazebo Harmonic, dev tooling, g2o deps. Self-contained (base image + `git clone`s, no local `COPY`). |
| `docker-compose.yml` | Runs the container, bind-mounts `workspace/` and `content/`. |
| `dps_slam.repos` | vcstool manifest: `dps_slam`, `dps_slam_msgs`, and g2o (pinned). |

## Prerequisites (host)

- Docker + Docker Compose v2
- [`python3-vcstool`](https://github.com/dirk-thomas/vcstool) — `sudo apt install python3-vcstool`
- [NVIDIA Container Toolkit][nvidia-toolkit] (the compose file uses `runtime: nvidia` — drop that
  line if you have no NVIDIA GPU)
- An X server (`$DISPLAY` / `$XAUTHORITY` set) and a running SSH agent (`$SSH_AUTH_SOCK`, forwarded
  into the container for git)

## Reproduce

```bash
git clone https://github.com/perezsaura-david/dps_slam_docker.git
cd dps_slam_docker

# 1. Assemble the workspace source (dps_slam + dps_slam_msgs + g2o), all pinned.
mkdir -p workspace/src
vcs import workspace/src < dps_slam.repos

# 2. Build the image and start the container (workspace/ is bind-mounted live).
docker compose build
docker compose up -d
docker exec -it dps_slam bash

# 3. Inside the container, build the workspace. colcon compiles g2o into
#    install/g2o (where dps_slam's cmake/FindG2O.cmake resolves it), then
#    dps_slam_msgs and dps_slam.
cd /root/workspace
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

## Notes

- `workspace/` and `content/` are gitignored: `workspace/src` is generated by `vcs import` and built
  by colcon; `content/` is local data (rosbags, launchers, logs) you supply yourself. Override their
  locations with `WORKSPACE_DIR` / `CONTENT_DIR` if they live elsewhere.
- The project's own packages track `main` in `dps_slam.repos`; pin them to commit SHAs for exact
  reproducibility. g2o is already pinned to a known-good commit.
- Personal dev-config mounts (nvim, tmux, gitconfig, claude) are commented out in the compose file —
  uncomment the ones you want.
